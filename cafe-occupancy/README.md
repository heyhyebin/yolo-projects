# YOLO 기반 카페 혼잡도 확인

카페 방문 전 빈자리 여부를 미리 확인할 수 있으면 좋겠다는 아이디어에서 시작한 개인 프로젝트입니다.

YOLO를 활용하여 카메라 영상에서 사람을 실시간으로 탐지하고, 전체 좌석 수 대비 탐지된 인원 비율을 계산하여 현재 카페의 혼잡도를 표시하는 MVP를 구현했습니다.

## 프로젝트 아이디어

카페에 방문했을 때 자리가 없어 다시 다른 카페를 찾아야 하는 불편함에서 아이디어를 얻었습니다.

카메라 영상을 활용하여 매장 내 인원과 혼잡도를 자동으로 파악하고, 사용자가 방문하기 전에 카페의 좌석 상황을 확인할 수 있는 기능을 구현하는 것을 목표로 시작했습니다.

현재는 아이디어의 가능성을 확인하기 위한 초기 단계로, YOLO의 사람 탐지 기능을 이용한 혼잡도 추정 기능을 구현했습니다.

## 주요 기능

- YOLO를 이용한 실시간 사람 탐지
- 웹캠 영상 입력 및 실시간 객체 탐지
- 탐지된 사람 수 자동 계산
- 설정된 전체 좌석 수 대비 인원 비율 계산
- 인원 비율에 따른 혼잡도 분류
  - `LOW` : 40% 이하
  - `MEDIUM` : 40% 초과 ~ 70% 이하
  - `CROWDED` : 70% 초과
- 영상에 전체 좌석 수, 탐지 인원, 점유율 및 혼잡 상태 표시

## 동작 과정

1. 웹캠을 통해 실시간 영상을 입력받습니다.
2. YOLO 모델을 이용하여 영상에서 `person` 객체만 탐지합니다.
3. 탐지된 사람의 수를 계산합니다.
4. 미리 설정한 전체 좌석 수와 탐지 인원을 이용하여 점유 비율을 계산합니다.
5. 계산된 비율에 따라 현재 상태를 `LOW`, `MEDIUM`, `CROWDED`로 분류합니다.
6. 결과를 실시간 영상 위에 표시합니다.

## 사용 기술

- Python
- YOLOv8
- Ultralytics
- OpenCV

## 현재 구현 범위

현재 버전은 실제 빈 좌석 자체를 직접 탐지하는 방식이 아니라, **카메라에서 탐지된 사람 수와 설정된 전체 좌석 수를 이용하여 매장의 혼잡도를 추정하는 MVP**입니다.

전체 좌석 수는 코드에서 직접 설정하며, 사람 수를 기반으로 매장의 점유 정도를 간단하게 확인할 수 있도록 구현했습니다.

## 향후 발전 방향

초기 아이디어인 실제 카페 빈자리 확인 기능으로 발전시키기 위해 다음과 같은 기능을 추가할 수 있습니다.

- 테이블 및 의자 객체 탐지
- 좌석별 사용 여부 판단
- 실제 빈 좌석 수 계산
- 여러 카메라를 활용한 매장 전체 좌석 분석
- 웹 또는 앱을 통한 실시간 좌석 정보 제공
