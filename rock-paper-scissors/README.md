# YOLO11 기반 2인 가위바위보 게임

Raspberry Pi와 YOLO11을 활용하여 두 플레이어의 손동작을 실시간으로 인식하고 가위바위보 게임을 진행하는 임베디드 프로젝트입니다.

## 프로젝트 소개

카메라 영상에서 YOLO11 모델을 이용해 **가위(Scissors), 바위(Rock), 보(Paper)** 동작을 인식합니다.

두 플레이어는 화면에서 손이 위치한 방향을 기준으로 구분하며, 버튼을 누르면 인식된 손동작을 바탕으로 승패를 판정합니다.

먼저 **3점을 획득한 플레이어가 최종 승리**하며, 승자가 결정되면 마리오 효과음이 재생된 후 프로그램이 종료됩니다.

## 주요 기능

- YOLO11을 이용한 실시간 가위·바위·보 손동작 인식
- 손의 화면상 위치를 기준으로 Player 1 / Player 2 구분
- 버튼 입력을 통한 승패 판정
- LED를 이용한 플레이어별 점수 표시
- Reset 버튼을 이용한 점수 초기화
- 3점 선취 방식의 게임 진행
- 최종 승리 시 마리오 효과음 재생 및 프로그램 종료

## 동작 과정

1. 프로그램 실행 후 카메라를 통해 두 플레이어의 손동작을 인식합니다.
2. Reset 버튼을 누르면 두 플레이어의 점수가 0점으로 초기화됩니다.
3. 화면에서 인식된 손의 위치를 기준으로 Player 1과 Player 2를 구분합니다.
4. 가위바위보를 진행하고 버튼을 누르면 현재 인식된 손동작으로 승패를 판정합니다.
5. 승리한 플레이어의 점수가 1점 증가하며 LED를 통해 현재 점수를 표시합니다.
6. 게임을 반복하여 한 플레이어가 먼저 3점을 획득하면 최종 승리합니다.
7. 최종 승자가 결정되면 마리오 효과음이 재생되고 프로그램이 종료됩니다.

## 실행 화면

프로젝트 시연 영상에서는 다음 과정을 확인할 수 있습니다.

- **영상 초반:** Reset 버튼을 이용하여 두 플레이어의 점수 초기화
- **게임 진행:** 두 플레이어의 가위·바위·보 동작 인식 및 승패 판정
- **점수 표시:** 승패 결과에 따라 LED를 이용하여 점수 표시
- **게임 종료:** 한 플레이어가 먼저 3점을 달성하면 마리오 효과음 재생 후 프로그램 종료
